# MediAssist Robots

## 41013 Industrial Robotics - Lab Assignment 2

An assistive robotic medication retrieval and delivery system for an aged-care environment.

The system uses two industrial robot arms to retrieve and deliver colour-coded dummy medication containers.

### Group Members

- Alessandro Dondina
- James Baker

### Robot Allocation

- Alessandro Dondina — Doosan M0609 (Robot 2)
- James Baker — Kawasaki RS007N (Robot 1)

### System Workflow

1. A medication and destination bed are selected.
2. Robot 1 retrieves the requested colour-coded dummy medication container.
3. Robot 1 places the container at a transfer point.
4. Robot 2 collects the container.
5. Robot 2 delivers it to the selected bedside location.

### Planned Features

- Two custom six-axis industrial robot models
- Pick-and-place operation
- Multiple bedside destinations
- Collision detection and avoidance
- Safety zones
- Emergency-stop functionality
- User interface for selecting medication and destination
- Real robot integration
